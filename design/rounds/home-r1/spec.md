# Home r1: the desk

The start screen people see every time they open Inkwell (a Windows PDF app, not a marketing page). The previous
attempt is the worktree-landing build (docs/screens/landing/ on that branch), judged by the user: "really generic
and screams AI". My reading of why: an indigo gradient app icon, a dashed upload box with an upload-arrow icon, a
grid of equal white cards with rounded corners, pill buttons, a faint purple gradient wash. Every piece is the
default SaaS template; nothing says "paper" or "ink". Kept from it: the facts it shows (recent files with a first
page, name, folder, pages, size, time; pinning; open by drop or Ctrl+O; Ctrl+K commands). Reopened: the whole look.

Idea: your documents are paper, and the start screen is where they lie waiting; opening one is picking it up.
For: one person on a big Windows desktop, opening PDFs many times a day. Feel: quiet, tactile, exact, unhurried.
Palette: paper #F3F0E8 ground; ink #17191D text; graphite #6E6A62 secondary text and rules; rule #D8D2C4 hairlines;
accent iron-gall blue-black #22386B, used once per region (a reason for blue: it is the colour of the ink the
product is named for). Dark theme later from the approved light one.
Type: a sharp transitional serif like Newsreader for the headline and file names; a plain grotesk like Inter for
UI; a monospace like IBM Plex Mono, small caps-size, for labels, counts and key hints.
Copy:
- Top left wordmark: "Inkwell". Top right: "Commands  Ctrl K" and "Light".
- Headline: "Drop a PDF anywhere." Under it: "Open file  Ctrl O".
- Index: "01 / RECENT". Files (name / folder / pages / time): Lease agreement.pdf (pinned) / Documents\Home / 3 pages / 3 h ago;
  Quarterly report Q3.pdf / Work\Finance / 24 pages / 12 min ago; Invoice 2026-0412.pdf / Downloads / 2 pages / yesterday;
  Conference notes.pdf / Documents\Work / 4 pages / 3 days ago; Thesis draft v4.pdf / Documents\Uni / 86 pages / 1 Oct.
- Footer: "Local. Nothing leaves this computer unless you ask the assistant."
Motion (for the build; renders are still): on launch the sheets settle into place one after another (stop-motion
12 fps, 40 ms apart); hovering a sheet lifts it a few millimetres (its shadow grows); dragging a PDF over the window
darkens the ground where it will land. Reduced motion: everything settled, hover only changes the shadow.
Must not appear: cards, tiles, equal boxes, dashed drop zones, upload/cloud icons, sparkles, gradients, glow, glass,
purple or indigo, pill buttons, app-icon squircles, people, hands, robots, laptop frames, browser chrome.

Verdict (2026-10-10): rejected. User: "This is not a website, its a desktop app, take reference from other similar apps, but I want not blocky/edgy components and corners etc, it should be rounded and smooth, same for assistant UI". Next round: real desktop-app chrome modelled on comparable PDF apps, rounded and smooth components.

## Shared

Render: a flat screenshot of one desktop application window at 1440 px wide, seen straight on, no OS title bar, no
browser chrome, no device frame. It is the start screen of a PDF reader called Inkwell, before any document is open.
Palette: warm paper ground #F3F0E8; ink #17191D for text; graphite #6E6A62 for secondary text and thin rules;
hairlines #D8D2C4; one accent, iron-gall blue-black #22386B, used at most once in each area. No other hues.
Type: headline and file names in a sharp transitional serif like Newsreader; interface text in a plain grotesk like
Inter; small labels, counts and keyboard hints in a small monospace like IBM Plex Mono.
Light and depth: soft daylight from the upper left. The only depth comes from real paper: sheets have a slight
thickness, a soft contact shadow and fine paper texture. Interface text sits flat on the ground with no boxes.
Composition: calm and editorial, asymmetric, at least 40 % of the window is empty paper ground. Small precise labels,
one large headline.
Must not appear: cards, tiles, rounded boxes around items, dashed drop zones, upload or cloud icons, sparkles,
gradients, glow, glass, purple or indigo, pill-shaped buttons, app-icon squircles, people, hands, robots, logos,
watermarks, extra text beyond the copy given.
